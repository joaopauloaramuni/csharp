# Relógio

> Projeto de estudo em C#, desenvolvido em 2011 enquanto eu trabalhava como estagiário C# na [Álamo TI](https://alamoti.net/).

## Sobre

Relógio digital que mostra a hora atual, atualizada continuamente.

## Funcionalidades

- Exibe a hora no formato longo (hh:mm:ss)

## O que pratiquei

- Componente `Timer` e evento `Tick`
- `DateTime.Now.ToLongTimeString()`

## Tecnologias

- C# / .NET Framework 4.0
- Windows Forms
- Visual Studio 2010

## Estrutura

```
Relógio/
├── Relógio/
│   ├── Form1.cs
│   ├── Program.cs
│   └── Relógio.csproj
└── Relógio.sln
```

## Como executar

1. Abra o `Relógio.sln` no Visual Studio (2010 ou mais recente; versões novas podem pedir para atualizar o projeto).
2. Compile e execute com **F5**.
