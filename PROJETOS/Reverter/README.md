# Reverter

> Projeto de estudo em C#, desenvolvido em 2011 enquanto eu trabalhava como estagiário C# na [Álamo TI](https://alamoti.net/).

## Sobre

Inverte um texto digitado (ex.: `abc` → `cba`).

## Funcionalidades

- Inverte a string com um clique
- Botão para limpar os campos

## O que pratiquei

- Manipulação de arrays de `char`
- Laço `for` com dois índices
- Lógica separada em uma classe (`Inverte.cs`)

## Tecnologias

- C# / .NET Framework 4.0
- Windows Forms
- Visual Studio 2010

## Estrutura

```
Reverter/
├── Reverter/
│   ├── Form1.cs
│   ├── Inverte.cs
│   ├── Program.cs
│   └── Reverter.csproj
└── Reverter.sln
```

## Como executar

1. Abra o `Reverter.sln` no Visual Studio (2010 ou mais recente; versões novas podem pedir para atualizar o projeto).
2. Compile e execute com **F5**.
