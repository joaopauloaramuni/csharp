# MiniNavegador

> Projeto de estudo em C#, desenvolvido em 2011 enquanto eu trabalhava como estagiário C# na [Álamo TI](https://alamoti.net/).

## Sobre

Navegador web minimalista: uma barra de endereço e uma área de exibição da página.

## Funcionalidades

- Digite uma URL e clique no botão para navegar

## O que pratiquei

- Controle `WebBrowser` do Windows Forms

## Tecnologias

- C# / .NET Framework 4.0
- Windows Forms
- Visual Studio 2010

## Estrutura

```
MiniNavegador/
├── Form1.cs
├── MiniNavegador.csproj
└── Program.cs
```

## Como executar

1. Abra o `MiniNavegador.csproj` no Visual Studio (2010 ou mais recente; versões novas podem pedir para atualizar o projeto).
2. Compile e execute com **F5**.

## Observações

- O controle `WebBrowser` usa o motor do Internet Explorer, então muitos sites modernos não são exibidos corretamente.
- Diferente dos outros projetos, aqui não há arquivo `.sln`: abra diretamente o `MiniNavegador.csproj`.
